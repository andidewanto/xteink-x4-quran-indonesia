# Lisensi dan Ketentuan Distribusi

Repositori ini terdiri dari beberapa jenis materi dengan status berbeda.

## File `.xtc`

File `.xtc` berisi materi Al-Qur'an, transliterasi, terjemahan, dan metadata dari sumber pihak ketiga melalui EQuran.id API. File dibagikan gratis untuk penggunaan pribadi dan edukasi. Ketentuan EQuran.id yang berlaku harus tetap dihormati: https://equran.id/terms.

## Source Code Generator

Apabila source code generator dipublikasikan di folder `generator/`, source code dapat diberi lisensi terpisah oleh pemilik proyek. Lisensi source code tidak otomatis memberikan hak atas data Al-Qur'an, transliterasi, terjemahan, audio, atau materi pihak ketiga lainnya.

## Dokumentasi dan Screenshot

Dokumentasi dan screenshot yang dibuat khusus untuk repositori ini boleh digunakan untuk menjelaskan, meninjau, atau membagikan proyek selama atribusi proyek dan sumber data tidak dihilangkan.

Hak dan ketentuan atas materi pihak ketiga tetap mengikuti pemilik atau penyedia sumber masing-masing.
