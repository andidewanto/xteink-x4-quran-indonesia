# Panduan Kontribusi

Kontribusi diterima untuk perbaikan layout, kompatibilitas perangkat, bug generator, dokumentasi, proses export `.xtc`, dan pelaporan file yang gagal dibuka atau tampil tidak sesuai.

Untuk masalah konten, sertakan nama dan nomor surah, nomor ayat, screenshot bila tersedia, isi yang tampil, dan referensi ke data sumber.

Perubahan terhadap teks Al-Qur'an, transliterasi, atau terjemahan harus dapat ditelusuri ke sumber resmi/proyek dan tidak didasarkan pada penyuntingan atau interpretasi pribadi.

Untuk Pull Request, jelaskan perubahan secara ringkas dan spesifik. Jika perubahan menyentuh layout, sertakan screenshot sebelum dan sesudah.
