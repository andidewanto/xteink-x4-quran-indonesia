# Atribusi dan Sumber Data

File `.xtc` dalam proyek ini dibuat menggunakan data dari **EQuran.id API v2**.

Dokumentasi EQuran.id menyebutkan bahwa sumber data Al-Qur'an yang digunakan adalah **Kementerian Agama Republik Indonesia**.

- https://equran.id/apidev
- https://equran.id/apidev/v2
- https://quran.kemenag.go.id/

Data yang digunakan mencakup nama dan nomor surah, nama Arab, arti nama surah, jumlah ayat, tempat turun, teks Arab, transliterasi Latin, dan terjemahan Bahasa Indonesia.

## Ketentuan EQuran.id

Ketentuan yang dirujuk: **Syarat & Ketentuan EQuran.id versi 1.0, berlaku sejak 15 Juni 2025**, ditinjau pada 6 Oktober 2026 (https://equran.id/terms). Pada versi tersebut:

- Konten boleh dibagikan dengan mencantumkan sumber dari EQuran.id (§3).
- Data yang diperoleh melalui API tidak boleh dijual (§5).
- Teks Al-Qur'an bebas digunakan, sedangkan terjemahan, tafsir, audio, dan fitur buatan EQuran.id dilindungi hak cipta dan penggunaannya mengikuti ketentuan yang berlaku (§7).

Ketentuan tertulis tersebut tidak menyebut pemegang hak atas terjemahan dan transliterasi, sehingga pemelihara repositori menanyakannya langsung kepada tim EQuran.id melalui email. Tim EQuran.id menjawab bahwa:

- Mereka tidak keberatan file turunan berformat `.xtc` yang memuat data dari API EQuran.id didistribusikan, selama sumber data dicantumkan dengan jelas, isi data tidak diubah sehingga mengubah maknanya, dan penggunaan tetap mengikuti ketentuan yang berlaku.
- Hak atas konten pihak ketiga, termasuk terjemahan Al-Qur'an dari Kementerian Agama Republik Indonesia, tetap pada sumber atau pemegang haknya. EQuran.id menyediakan data tersebut melalui API dan tidak mengklaim kepemilikan.
- Pengambilan data satu kali per surah oleh generator tidak bermasalah terkait rate limiting.
- Untuk penggunaan komersial atau distribusi dalam bentuk lain, pengguna diminta menghubungi EQuran.id kembali.

Jawaban tersebut tidak menyebut sumber transliterasi Latin secara terpisah; sumbernya belum dikonfirmasi dan tidak diklaim oleh proyek ini.

## Atribusi yang Disarankan

> Sumber data Al-Qur'an: EQuran.id (https://equran.id). Terjemahan Bahasa Indonesia: Kementerian Agama Republik Indonesia.

Tautan menuju EQuran.id sangat dihargai. Gunakan atribusi ini saat membagikan ulang file `.xtc`.

Ketentuan dapat berubah; periksa versi terbaru di https://equran.id/terms.

## Permintaan Penghapusan atau Koreksi

Pemegang hak atas materi dalam proyek ini dapat meminta penghapusan atau perubahan atribusi melalui GitHub Issue di repositori ini. File yang bersangkutan akan ditarik dari distribusi apabila diminta oleh pemegang hak.

## Kepemilikan

Pemelihara repositori tidak mengklaim kepemilikan atas teks Al-Qur'an, terjemahan, transliterasi, atau data pihak ketiga.
